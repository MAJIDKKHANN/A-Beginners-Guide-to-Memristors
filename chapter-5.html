Chapter 5 · Memory

Storing 0s and 1s

A memristor has two states it holds without power. That is exactly what you need to store a bit. Here is how writing and reading work.

Choosing a 0 and a 1

We just agree on a rule: high resistance means 0, low resistance means 1. Some chips use the opposite rule. It does not matter, as long as everyone agrees.

Memory that keeps its data without power is called non-volatile. The flash memory in a USB stick is non-volatile too, but a memristor can be faster, smaller and use less energy to write.

Writing and reading

Writing means using a big push (around 1 volt or more) to SET or RESET the memristor. Reading means using a tiny push, maybe 0.1 or 0.2 volts, and measuring how much current comes out. The read push is far too small to move the door, so reading does not change the stored bit.

Like peeking through the door

Reading is like peeking to see if the door is open, without touching it. Writing is actually pushing the door.

More than one bit per memristor

Remember the dimmer from Chapter 1? If we can reliably put the door in four different positions, one memristor can store two bits: 00, 01, 10 or 11. This is called multi-level cell storage. The catch is that the positions must not drift into each other, so it needs careful control.

Is it real yet?

Yes. ReRAM is already built into some real chips today, mostly as small built-in memory inside microcontrollers, the little computers found in gadgets and cars. It is not yet replacing the main memory in your phone or laptop, but it is used where low power and keeping data without a battery matter.

Remember the trade-off

Every SET and RESET wears the bridge a little. The number of times a memristor can be rewritten before it fails is called its endurance. How long it keeps data without power is called its retention.

What we learned

  • HRS stores a 0, LRS stores a 1 (or the other way round).
  • Memory that keeps data without power is non-volatile.
  • Big pulses write. Small pulses read without changing anything.
  • With careful control, one memristor can store more than one bit.
  • Endurance is how many rewrites it survives. Retention is how long it remembers.
